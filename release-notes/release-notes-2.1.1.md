# CLI::Simple 2.1.1 Release Notes

**Release Date:** 2026-07-20
**Distribution:** CLI-Simple
**Author:** Rob Lauer

---

## Overview

Version 2.1.1 is a patch release that fixes pager output behaviour in
non-interactive environments and improves the build system's
dependency management. No API changes are introduced.

---

## What's Changed

### Bug Fixes

#### Pager No Longer Activates in Non-Interactive Environments

`IO::Pager` is now only invoked when both `$PAGER` is set **and** the
process is attached to an interactive terminal. Previously, pager
support was gated solely on the `$PAGER` package variable, which could
cause unexpected behaviour when `--help` output was piped, redirected,
or consumed by automated tooling.

```perl
# Before
if ($PAGER) { ... }

# After
if ( $PAGER && IO::Interactive::is_interactive ) { ... }
```

This change requires the new `IO::Interactive` dependency (see below).

---

### New Dependencies

| Module | Minimum Version |
|---|---|
| `IO::Interactive` | 1.027 |

Added to both `requires` and `cpanfile`.

---

### Build System Improvements

#### Automatic Dependency Tracking (`deps.mk`)

A new generated makefile, `deps.mk`, provides auto-computed
inter-module dependency edges for the build. It is regenerated
whenever the built `.pm` files change:

```makefile
deps.mk: $(PERL_MODULES)
    cmb create-deps > $@
```

#### Safe `deps.mk` Inclusion

`deps.mk` is conditionally included in `perl.mk` — it is skipped for
`clean` and `distclean` goals. This prevents GNU Make from building
all `.pm` files only to immediately delete them during a clean run.

#### `project.mk` Simplified

Hand-maintained module dependency recipes have been removed from
`project.mk` and are now autogenerated by
`CPAN::Maker::Bootstrapper`. `project.mk` itself remains
unconditionally included so that any `clean-local::` hooks it contains
are always executed.

#### `SKIP_TESTS` Support in `Makefile`

The top-level `Makefile` now honours a `SKIP_TESTS` environment
variable, passing `--skip-tests` through to `cpan-maker` when set.

---

## Upgrade Notes

- Install `IO::Interactive` if it is not already present:
  ```
  cpanm IO::Interactive
  ```
- No changes to the public API; existing scripts require no
  modification.
- If you maintain a fork of `project.mk` that contains module
  dependency rules, note that those rules are now expected to be
  autogenerated by `CPAN::Maker::Bootstrapper` via the new `deps.mk`
  mechanism.
